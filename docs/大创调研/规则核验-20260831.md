# 电子科技大学大创结题与创新年会：首轮规则核验

检索与核验日期：2026-08-31。适用对象：计算机科学与工程学院已立项项目，用户目前判断为校级。核验责任：主负责人。状态为 `interpretation-verified` 的结论，仅在所列来源的年度和适用范围内成立；不代表已经获得学校对本项目的资格确认。

## 1. 结论与边界

优先准备2026年优秀结题，同时保留2027年成果展示的选择是合理的规划，但它不是已经确认的自动晋级链。结题成绩、国家/省级立项资格和年会推荐是不同机制。

学院已公布的2026年项目安排支持“十月结题”的判断；本轮没有检得本院2026年专门结题通知或2027年目标年会通知，因此确切日期和2027年规则尚未确认。不能把搜索未命中写成“通知一定不存在”。

## 3. 省年会与全国年会资格

**四川省年会。** 成电电子实验中心转载的2026年第二届省年会遴选通知，第三部分第1点面向2023–2025年参加校级立项且通过结题的学生，并明确排除2026年立项项目。因此，2026年结题后争取2027年是可进一步核验的规划，而不是当前已经获得资格。通知第一部分使用“省创计划”称谓，第三部分却以校级立项经历表述范围；缺少原始附件和学校进一步说明时，既不能断言只限省级，也不能保证所有校级项目均符合最终资格。S04，`interpretation-verified`，存在明确范围歧义。

**全国年会。** 全国平台2025年正式要求，以及暨南大学2026年通知所附第十九届准备及遴选要求，均要求学术论文、改革成果展示标注国家级项目编号/资助。当前仅校级的项目不能据此直接视为满足条件。创业推介另有其他来源和身份要求，不能为了规避条件把创新训练项目包装成不存在的创业实践。S05、S07，`interpretation-verified`；S07为高校官网转载版本，2027年仍需重新确认。

**推荐通道。** 全国规则明确中央部委所属高校可以直接按限额推荐，地方高校经省级教育行政部门组织。成电官网确认学校为教育部直属高校。因此“必须先在四川省年会获奖，才能参加全国年会”不成立；成电具体采取哪一种校内遴选和培育安排仍以本校通知为准。S05第四部分、S06学校简介、S07对应段落，`interpretation-verified`。

S04第五部分只说明入选省年会有机会获优先推荐全国，不保证推荐或获奖。S04网页标注2026-06-02，但学生提交截止写6月1日，存在转载日期晚于截止的问题，不据其推定下一年申报日。优秀结题可能增强校内竞争力，但已核验材料未把它规定为全国统一的充分条件。

## 4. 评价依据与项目交付的关系

东南大学2026-07-27预选通知附件8《全国大学生创新年会作品评审指标》全文已通过Tavily提取，以下是该附件表2“改革成果项目”的权重。它是高校当年公开采用的全国年会指标版本，**不是成电2026结题打分表，也不是已确认的2027标准**。来源S09，`interpretation-verified`。

| 评分项 | 权重 | 本项目应准备的证据（研究团队的落实建议，不是官方额外条款） |
|---|---:|---|
| 选题 | 10% | 具体使用者、实际问题、现有方法不足，避免泛泛的区块链背景 |
| 自主性 | 10% | 学生分工、独立设计/实现/实验记录，能够现场解释技术选择 |
| 创新性 | 30% | 可验证的新想法及训练成效；用比较和迭代说明学生解决了什么问题 |
| 过程完整性 | 20% | 立题依据、数据资料、设计、实现、失败与修改记录能够追溯 |
| 成果 | 20% | 真实可用的软件/平台或其他成果，以及支持实用价值的验证 |
| 展示效果 | 10% | 主题清楚、关键过程可演示、图文规范，能够解释结果及边界 |

需要特别防止误读：该表“创新性”的说明侧重学生创新思维、自主学习、实践、合作和科研方法的培养成效，并非把30%全部分配给算法新颖性。其“成果”列包含论文、实物、软件、服务平台等，不是只认论文。另一方面，界面漂亮不能替代自主性、过程和真实成果；表中单列的展示效果仅为10%。不能由权重反推出“做一个界面就容易获奖”，也不能用现有演示代理数据充当真实算法效果。

同一附件的学术论文指标为选题15%、结构规范15%、内容25%、创新性30%、研究价值15%。两类通道对证据组织的要求不同，不能将展示型成果和论文型成果的权重混算。本项目可优先比较“成果展示为主、严谨实验支撑”的交付形式，但这还不是最终方向决定。

成电S04明确优先考虑高水平已发表论文，以及具有竞赛、专利、论文等成果或可展示实物的项目。这些是该次遴选的优先事项，未找到适用于本项目的统一“一个专利加几分”规则。软件著作权、专利、论文是否值得投入，须依据实质成果、周期与正式要求决定，不先堆证书。

**建议的十月交付标准，尚未冻结：** 一个明确问题；至少一项经过对照验证的实质改进；一套能重放的核心功能演示；有依据的标签与时间信息边界；可追溯的过程、分工和经费；符合学院模板的结题论文与答辩材料。若选择风险相关功能，必须取得匹配的风险标签或可靠事件证据，不能把实体类型重命名为风险。
