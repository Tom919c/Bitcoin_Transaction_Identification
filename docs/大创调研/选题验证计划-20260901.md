# 高质量大创方向：选题验证计划与证据增量

日期：2026-09-01。输入基线：提交 `33ed8a9`、[方向重评](方向重评-20260831.md)及本轮公开来源。状态：Gate 0–2，尚未形成通过全部门槛的最终主方向。用户要求“制定计划，确保找到最佳方向后继续下一步研究”；这不是对M或任何候选的确认。

## 1. 重新规定完成标准

目标是找到在已审计候选、数据和证据范围内最有支持的高质量大创方向，不能保证全球最优、获奖或从未有人做过。交付计划不等于完成选题；选题也不等于创新已经得到实验支持。

本轮纠正两点：第一，M得到的核验较深，不等于它比其余候选更有创新性；第二，N2若最终只能评价钱包权限或付款／找零，就可能与M共享同一问题，不能作为独立替代凑数。因此暂时取消“已确定一个主方向和两个独立替代”的表述：M、N2、N3均继续接受准入审计，M只是先核验的候选。

工作量、开发周期、实现复杂度、团队人数和可用算力不进入选题排名。许可、标签含义、观察信息、可证伪性和独立真值仍是科学条件。不能以“缺现成数据”直接否决一个可建立可信受控数据的方向，也不能把“将来可以生成数据”当作数据已就绪。

## 2. 先过硬门，再比较价值

| 门槛 | 通过所需证据 | 未通过时的处理 |
|---|---|---|
| 原题与真实问题 | 明确服务对象、决策场景、错误造成的影响；与原申报任务的实质联系。正式任务书尚缺，技术调研可以继续，行政适配不得宣称已确认 | 补证；不得用界面数量、算法名称或工程规模代替问题价值 |
| 标签与可见信息 | 预测单位、真值定义、获取方法与时间；真值不能由被评测规则生成；隐藏权限和事后信息不偷偷进入输入 | 缩小可支持的结论或否决任务；十一类实体标签不转换为违法性 |
| 最近邻与创新增量 | 关键前作全文定位；逐项说明已有组件、等价问题、剩余假设；主动找可直接完成任务的简单方法 | 与前作等价则停止该创新主张；“没搜到”不算首次性证据 |
| 可证伪评价 | 有独立评价单位、明确反例、强基线和同时体现收益／损失的指标；后续能据结果停止方向 | 无法被可靠结果否决的叙事不晋级 |
| 数据及实现依据 | 区分文档、代码、模拟测试、有效工件和运行结果；受控任务须有独立真值生成与协议校验的可审计路线 | 仅缺实现完成度不是创新否决；关键真值或协议前提不成立则不能晋级 |
| 结论边界及风险 | 受控机制不冒充主网规模；举报文本不冒充犯罪事实；权限域不冒充自然人；来源许可与安全边界清楚 | 修改任务或停止，不能靠答辩包装修补 |

通过硬门后，再比较问题重要性、创新增量、证据强度、实验判别力及成果对大创培养和展示的价值，不虚构精确权重或获奖概率。若所有候选都不过门，应扩大选题，不能在失败候选中强行选第一。

候选晋级所需的是关键前提可成立、实验确实能判别；方法优越性和实际效应必须由后续预注册实验检验。不能要求在协议冻结前就证明性能提升，也不能先声称效果成立。
