## 3. 全文反证边界

全文检索中，`as-of`、`causal`、`temporal graph` 和 `replay` 均无命中；`future` 的少量命中未形成 future-information leakage 定义或审计。原文明确的 leakage 控制是训练/验证集中 prefix clusters 互斥（PDF 111 / 印刷页 95），它只支持簇重叠隔离，不能外推为未来信息泄漏或严格历史回放已被控制。

| 证据 | 精确定位 | 对本项目的含义 |
|---|---|---|
| 全链数据先聚类，再生成簇级 5,035 天收/支时间序列 | PDF 106 / 印刷页 90，§5.3.4 Steps 1--2 | 全局数据截止不等于每个决策点的 as-of 截止；原文未说明按样本 cutoff 重放聚类。 |

结论不变：BitLINK 足以否决通用 temporal cluster linkage、successor-cluster prediction 和 cluster-chain 首创主张；它未给出固定历史支持上只替换 `C_t/C_T`、成对量化分区/实体图重写并向下游决策传播的完整等价设计。这个窄差异仍只是待 S0 证伪的研究对象，不是已证明的新颖性。
