# 严格按时可见实体图研究启动章程

日期：2026-09-08

状态：主方向已获用户确认；Gate 2 关闭，Gate 3A 准备中，尚未冻结实验协议

研究分支：`asof-entity-graph-pilot`

基线提交：`bc5703a650587643fca7140fc579310c6f09349e`

## 1. 正式决策

本项目确认以下方向为当前唯一主方向：

> 面向历史回放的比特币实体图可信识别：研究未来聚类信息泄漏，构建按时间可见的实体图、可信评测方法和人工审查系统。

核心研究问题是：在历史截止时点 `t` 预测实体类型时，使用全观察期结束后才形成的最终地址分区 `C_T`，而不是当时可见的地址分区 `C_t`，是否会显著改变实体图结构、标签投影、模型排序、校准和有限审查预算下的决策，从而使历史回放评测产生系统性偏差？

2026-09-08 聚焦反证后的创新边界：未来聚类知识回写历史会产生 look-ahead bias，已经被 Glassnode 的 point-in-time 数据实践直接描述；“用 GNN 表征细化启发式 cluster 并发现可疑错误合并”也已被 2026-09-01 的预印本直接覆盖。本项目不以发现该现象或一般聚类置信度方法为创新，研究增量收紧为：在固定原始链前缀、地址支持、标签口径和训练预算下，受控测量 final-vintage 与 as-of 分区对实体图、实体类型预测、校准、选择性预测和有限审查队列的影响，并分解 partition、cluster-quality、label-vintage 与普通时间漂移。

该决定终止以下路线作为主线：

- 继续通过更换 GNN 模块追求随机切分上的更高 F1；
- 在当前终态聚类图上继续扩大通用 DGI 或特征遮盖式自监督预训练；
- 在缺少真实语义标签时把 PayJoin 识别包装成非法活动识别。

这些资产可以作为严格历史图上的基线、扩展或负结果，不再定义研究问题。

## 2. 科学边界

- `0–10` 是已有监督实体类型标签，不是非法、欺诈或 AML 风险标签。
- `-1` 是未标注图上下文，不作为正常类、负类或未知非法类。
- 地址聚类是带规则和误差的实体近似，不是真实主体所有权真值。
- 使用最终聚类回放历史只有在明确的历史部署问题下才构成待检验的未来信息问题；本项目不预设泄漏必然存在或影响必然很大。
- 当前本地 2.52 亿节点数据库缺少地址到实体的历史映射和 union provenance，不能逆推出严格 `C_t`。首个数据 Gate 必须回到可审计的原始链数据或等价上游工件。
- 在聚焦最近邻全文核验完成前，不使用“首次”“SOTA”或“已解决时间泛化”等表述。

## 3. 可证伪假设与对照

主假设：相同地址全集、相同信息截止和相同标签规则下，最终分区 `C_T` 相比 as-of 分区 `C_t` 会产生可重复的跨时合并、实体边重写或标签冲突，并改变至少一种下游决策结论。

零假设：上述结构差异不存在、规模很小、对过滤规则不稳定，或不足以改变模型排序、校准或有限预算审查结果。零假设成立时，停止以“未来实体身份泄漏”为核心创新，不追加复杂模型。

冻结协议将保留四个条件：

| 条件 | 实体身份 | 边和特征信息 | 用途 |
|---|---|---|---|
| A | 最终聚类 `C_T` | 完整观察期 | 回顾性静态参考，不代表部署 |
| B | 最终聚类 `C_T` | 截止 `t` | 隔离实体身份中的未来信息 |
| C | as-of 聚类 `C_t` | 截止 `t` | 严格历史可见基线 |
| D | as-of 聚类 `C_t` 与聚类细化/置信度 | 截止 `t` | 条件 C 通过数据 Gate 后才评估的最近邻基线或扩展；不预设创新 |

主诊断是 B 与 C 的差异。A 不能作为部署性能；D 不能在 B/C 数据 Gate 失败时通过模型复杂度继续推进。

### Gate 3A

Gate 3A 尚未冻结。以下事项必须先关闭：

1. 原始链数据来源、版本、许可、获取日期、哈希、区块范围和重组处理规则；
2. 地址或脚本标识单位，以及 P2PK、P2PKH、P2SH、SegWit、Taproot 和不可解析脚本的处理；
3. union 事件的区块高度、区块内顺序、启发式类型、规则版本和证据字段；
4. CoinJoin、PayJoin 及其他协作交易的排除规则、无法判定语义和敏感性条件；
5. as-of 实体拆分后的标签投影、标签冲突、标签可得时间和未标注语义；
6. 目标地址交集、时间 cutoff、训练/验证/测试切分和所有特征的可得时间；
7. 无模型数据 Gate 的主要统计量、数值 Go/No-Go 阈值和重采样单位；
8. 测试集打开次数、调参预算、种子、主要指标、统计方法和结论降级规则。

上述内容冻结为版本化协议前，不训练新模型、不打开正式测试期结果、不重建 2.52 亿级全图。

## 5. 第一阶段：小窗口无模型数据 Gate

第一阶段只回答数据机制是否真实存在并足以继续研究：

1. 选择多个代表性小区块窗口，记录选择理由；窗口不得依据下游模型结果挑选。
2. 按主链顺序处理交易，在每次地址合并前记录 provenance，并能从空状态确定性重放到任意 cutoff。
3. 在同一地址交集上生成 B 和 C 两种分区及实体图；不得用最终 alias 反投影代替 as-of 重放。
4. 报告未来合并地址比例、分量拆分/合并分布、实体节点变化、边重写比例、标签冲突和未投影比例。
5. 至少比较保守与宽松两种协作交易过滤条件；差异若只在单一过滤器下出现，不能晋级。
6. 保存 manifest、配置、日志、原始统计和 Git revision；负结果同样登记。

Go 条件：核心结构影响跨窗口、跨合理过滤条件稳定，且满足 Gate 3A 预先冻结的数值阈值。

No-Go 条件：无法构建可审计的 `C_t`；标签不能公平投影；影响接近零或仅来自普通特征重算；结论对合理过滤条件翻转；聚焦检索发现完整等价工作。

数值阈值不得在查看数据 Gate 结果后补写。

## 6. 通过数据 Gate 后的最小实验

仅在 Go 后启动：

- 规则与 tabular 基线：多数类、逻辑回归、树模型；
- 非图基线：MLP；
- 最小图基线：现有 GraphSAGE 与 EGS，作为历史资产复用，不预设其领先；
- 指标：Macro-F1、AUPRC、ECE/可靠性、选择性风险—覆盖率、固定预算 top-k overlap 与 yield；
- 分析：B/C 模型排名变化、类别级差异、置信度漂移、实体拆分/合并案例、时间块或实体簇级不确定性。

模型只用于检验构图口径是否改变结论。若简单非图模型已充分解释差异，不新增 GNN 架构。

## 7. 系统交付与保底

BitRiskLens 作为展示外壳，后续只接入可追溯实验产物。系统应支持历史 cutoff 回放、实体合并来源、B/C 图差异、置信度与拒判、人工复核记录和报告导出。界面使用“实体类型识别结果”“待复核对象”等措辞，不把模型输出描述为犯罪事实或真实主体风险。

若核心数据 Gate No-Go，保留同一系统方向，交付严格时间外测试、类别错误分析、校准、拒判、局部图解释和证据追踪；同时明确论文创新性降级，不用展示系统替代科学证据。
