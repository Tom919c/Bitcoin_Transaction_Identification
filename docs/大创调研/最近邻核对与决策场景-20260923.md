## 2. 具体使用者与其历史时点决定

- **使用者**：某 VASP（或交易所）合规调查组的一名调查员。
- **历史时点**：冻结协议中的一个 cutoff `t`（`181440`、`199584`、`215712`、`225792` 之一，对应 2012–2013 年）。
- **他在 `t` 时必须做的决定**：在人工复核预算有限的前提下，决定把哪些实体放进下一窗口的复核队列。可用信息只有 `t` 之前可见的链上数据，以及在该数据上构建的实体图。
- **关键限制**：`t` 时实际可得的标签集 `L_{<=t}` 目前**不可构造**（见 [S1 标签证据表](S1标签证据表-20260923.md)）。因此该场景现阶段只能作为**回顾性**框架使用，不得表述为历史部署性能或"当时可识别"。

## 3. 可检验的决策指标

分为两档：只用无标签结构量（S0 即可给出）与需要标签（S1 之后且只能作回顾性敏感性）。

**A. 只用无标签结构量（S0 范围内）**

| 指标 | 定义 | 判据形式 |
| --- | --- | --- |
| 队列组成差异 | 固定预算 `K ∈ {1%, 5%}` 下，B（`C_T`）与 C（`C_t`）两版分区按**同一冻结评分函数**取出的实体队列，其重叠率 `|Q_B(K) ∩ Q_C(K)| / K` | 零假设为"分区版本不影响队列"；重叠率显著低于 1 即说明分区版本改变了调查目标 |
| 分区重写量 | `p_merge`、`p_rewrite` 及其 95% CI（S0 主指标） | 已在 Gate 3A v1.3 冻结 |
| 结构传播 | 受影响 CT 实体比例、节点压缩比例、跨实体端点对塌缩为自环的比例、边聚合比例、合并簇组数与规模分位、金额加权端点重写比例、`variation_of_information` | S0 次要指标，只解释机制 |

**B. 需要标签（S1 之后，只能作回顾性敏感性）**

| 指标 | 定义 |
| --- | --- |
| 队列 yield 差 | `yield_B(K) - yield_C(K)`，yield 指队列内已标注实体类型的构成。**yield 不是非法活动命中率** |
| 模型侧配对差 | 同一模型在 B/C 下的 Macro-F1、逐类 F1、macro one-vs-rest AUPRC、Brier、ECE、错误—覆盖曲线的配对差 |
| 排名翻转 | 同一模型在 B/C 下的模型排名是否翻转 |

**可预注册的表述形式（示例，非最终措辞）**

> 在固定预算 `K ∈ {1%, 5%}` 下，令 `Q_B(K)`、`Q_C(K)` 分别为 B、C 分区下按同一冻结评分函数取出的实体队列。主要可检验量为队列重叠率 `|Q_B(K) ∩ Q_C(K)| / K`；若其显著低于 1，则分区版本改变了人工复核的目标集合。`yield` 差只能在取得可审计 `L_{<=t}` 后检验，且必须标注为回顾性敏感性，不得外推为历史部署表现。

## 4. 边界与前置

- 本文件不主张新颖性结论。组件级碰撞已确认、完整等价未成立，最终由 S0 证伪或确认。
- 不把"发现 look-ahead"当作本项目贡献；不把 `yield` 表述为非法活动命中率；不把回顾性结果表述为历史部署或 AML 风险识别。
- 上述决策指标的实现细节（评分函数、tie-break、B/C 实体匹配、队列去重、分母定义）必须在 **S1 协议冻结之后**才能使用；本文件只定义可检验的方向，不构成 S1 协议。
