## 3. 结论与边界

当前**不能**构造可审计的 `L_{<=t}`。把最终标签回写到历史 `C_t` 会引入与本项目核心问题同类的未来信息风险。

因此 S1 的准入判定维持 2026-09-13 的结论：S0 不受影响；严格历史部署语义下的 S1/S2 暂不准入；S1 的最高可信范围是**回顾性实体类型敏感性分析**，且须在 S0 Go 与独立 S1 协议冻结之后；S2 历史时点识别为 No-Go。代码中的二元敏感组不得作为 S1 主标签或论文中的 AML ground truth。

## 4. 关闭缺口所需的最小证据包

1. 每条标签的稳定记录 ID、原始实体／地址标识、类别原文、来源 URL 或正式出处；
2. 首次发现、首次公开、本项目采集与任何更正／撤销时间，并说明缺失值与时区；
3. 来源许可、允许用途、版本、文件哈希与获取日期；
4. 置信度、证据等级、冲突合并与删失规则；
5. 地址到原始 locking script、`C_t`、`C_T` 与模型节点的可重放映射，含一对多、多对一及无法投影的分母；
6. 在不读取正式测试集的前提下冻结 `L_{<=t}` 构造、训练／验证 cutoff、未知与未标注处理，以及标签漂移敏感性。
