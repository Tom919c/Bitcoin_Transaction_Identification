# S1 研究问题与主要指标（一页）

日期：2026-09-25。性质：**S1 协议起草的输入，不是 S1 协议本身。** S1 协议须另行冻结，不得沿用 S0 阈值。本页仅收敛研究问题与指标框架，实现细节（评分函数、tie-break、分母）待协议冻结时确定。

依据导师 2026-09-25 指令：先确定**一个具体使用者**和**一个主要判断问题**，再固定可比较的评测单位、标签冲突与缺失处理、主要指标、简单基线和停止条件；模型排序、校准、选择性预测**保留为次要问题，不能全部并列为主目标**。

## 1. 一个具体使用者

**某 VASP（虚拟资产服务商）合规调查组的一名调查员。**

- 历史时点：冻结协议中的一个 cutoff `t_j ∈ {181440, 199584, 215712, 225792}`。
- 他在 `t_j` 时必须做的决定：在**人工复核预算有限**的前提下，决定把哪些实体放进下一窗口的复核队列。
- 他可用的信息**只有** `t_j` 之前可见的链上数据，以及**以该数据构建**的实体图。

这个使用者的关键特征是：他必须**当下**做决定，无法等到 2024 年拿到更完整的聚类。

## 2. 一个主要判断问题

> **在固定人工复核预算下，调查员在 `t_j` 按当时可见实体图排出的复核队列，是否与他日后用更晚分区版本排出的队列指向同一批实体？**

若指向不同，说明"实体身份"这一层就带有未来信息——调查员当时**不可能**排出那个队列，任何以晚近分区回放评测的历史表现都会被高估。

副问（次要，仅解释机制）：这种差异是否足以改变模型**排序**、**校准**与**选择性预测**？——**这三个是次要问题，不作为主目标。**

## 3. 可比较的评测单位

**主要单位：`(window_id, filter_profile, budget K)` 下的实体队列。**

| 维度 | 取值 | 说明 |
| --- | --- | --- |
| `window_id` | `t181440`, `t199584`, `t215712`, `t225792` | 沿用 S0 冻结的四 cutoff |
| `filter_profile` | `F_pub`, `F_wide` | 沿用 S0 主 profile；`F_none` 仅诊断 |
| `budget K` | `1%`, `5%` | 协议 §9 已固定 |
| 配对方式 | B/C **同支持、同交易窗口、同评分函数** | 唯一允许的差异是分区版本 |

实体级配对须**同时**报告两种口径（协议 §9 要求）：node-level 与 script-anchor-weighted。`C_t` 与 `C_{T_j}|V_j` 的实体匹配规则、队列去重规则须在协议中冻结。

## 4. 标签冲突与缺失处理

依据 S0 协议 §9 与论文实际做法：

| 情形 | 处理 | 依据 |
| --- | --- | --- |
| 同一 cluster 内多个不同实体类型 | 记为**冲突**，不按多数票覆盖 | 协议 §9 明文 |
| 冲突的最终处理（移除／拒判／仅描述） | **S1 协议须明确定一种，并固定分母** | 协议 §9 要求 |
| `-1` | 保持**未标注**，不作负类 | 协议 §9 明文 |
| 无法投影到 `C_t` 的标签 | 记录未投影比例，**不静默丢弃** | 协议 §9 要求 |
| 来源侧既有做法 | 原论文对冲突 cluster **直接不标注** | arXiv 2411.10325 |

**待决：** 原论文"冲突即不标注"会丢失信息且不可追溯。S1 建议改为**标记冲突 + 明确移除规则 + 报告移除分母**，但此为**拟作决定，须提交导师审核后再执行**。

## 5. 主要指标

**唯一主指标：队列重叠率。**

```
overlap(K) = |Q_B(K) ∩ Q_C(K)| / K
```

其中 `Q_B(K)`、`Q_C(K)` 为 B、C 分区下按**同一冻结评分函数**取出的前 `K` 实体队列。

- 零假设：分区版本不影响队列 → `overlap(K) = 1`。
- 判定形式：`overlap(K)` 显著低于 1，即分区版本改变了人工复核的目标集合。
- 报告：按 `(window_id, filter_profile, K)` 给出点估计与不确定性区间；不确定性须**按时间块或实体簇重采样**，不把地址或交易行当独立同分布样本。

**这个指标的优点：** 不依赖标签，因此**在标签瓶颈未解除时仍可执行**，是 S1 在方案 B（无标签结构审计）下也能保留的指标。

辅助报告量（**不作为主判据**）：S0 已有的 `p_merge`、`p_rewrite` 与结构传播量（受影响 CT 实体比例、节点压缩、自环塌缩、边聚合、`variation_of_information`）。

## 6. 简单基线

按协议 §9 首轮清单，**先跑最简基线，不预设 GNN 领先**：

1. 多数类；
2. 逻辑回归；
3. 一个树模型；
4. MLP；
5. 现有 GraphSAGE 与 EGS（历史资产复用）。

**一个前置判断：** 若简单非图模型已能充分解释 B/C 差异，**不新增 GNN 架构**（章程 §6 明文）。S1 需先回答"差异是否在模型层就已存在"，再决定是否值得上图模型。

另需一个**无模型结构基线**：直接比较 B/C 两版图的节点数、边数、分量结构，作为"差异是否只是技术性重算"的对照。

## 7. 停止条件

| 情形 | 动作 |
| --- | --- |
| `overlap(K)` 在所有窗口与 profile 下均不显著低于 1 | **No-Go**：分区版本不改变复核目标，停止以"未来实体身份泄漏"为核心的模型创新 |
| `overlap(K)` 显著低于 1，但**仅在单一 filter profile 下成立** | 不晋级（跨配置稳健性不足） |
| 标签仍不可构造 | 只能执行**无标签结构审计**（方案 B），主要指标仍用 `overlap(K)` 的**结构版**（评分函数改为无标签结构量），明确标注为回顾性 |
| 测试集已打开或协议被改 | 触发 24 小时专项汇报 |

**预算与纪律：** 测试集只在配置、manifest 与 decision log 锁定后**打开一次**；每个学习模型用同一组五个种子；最多 20 个验证集超参配置；**不新增 GNN 架构或预训练任务**。
