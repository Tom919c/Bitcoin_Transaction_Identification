## 3. 大创阶段的决策流程

1. **规则与范围核验**：区分结题、立项层级遴选、校内专项奖励、省年会、全国年会及其他竞赛；核对原申报书、完成标准和可用资源。
2. **问题与作品比较**：研究真实使用场景、已有系统、代表性获奖作品和相关技术文献；形成约8–12个候选，比较创新价值、证据、可完成性、展示性和失败条件。获奖案例只说明已有作品形式，不能证明某个技术或包装导致获奖。
3. **用户确认主问题后冻结验收协议**：一个主方向、两个替代和保底交付；明确数据、任务、指标、基线、时间信息边界、演示验收条件及停止条件。不得将方向讨论直接当作模型开发许可。
4. **低成本验证后实施**：先复用现有资源验证核心创新，再决定是否扩大实验；最终形成可信功能、实验对照、失败案例、过程记录、结题论文和答辩材料。
5. **年会增量准备**：在结题成果上深化，分别核验2027年的立项资格、推荐通道、学生身份、材料和名额；不为未确认的年会要求牺牲十月交付。

两条文献检索链仍保留：Undermind用于学术深检和组织，独立官方论文/数据/代码检索用于核验和反证。Zotero用于经过核验的核心文献。当前是官方规则核验，不能把政策网页数当成学术文献阅读量，也不声称已经完成此前147篇初筛、60篇来源核验或30篇全文阅读的要求。
