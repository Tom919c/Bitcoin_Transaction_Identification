## Verdict

冲刺一应收缩为三个可在现有协议图上完成、且能快速证伪的方向：

1. **先补强基线与漂移诊断**：EGS 三种子 temporal 重跑、Dir-SAGE、CPU GBDT。目的不是追分，而是先判断 temporal 崩溃究竟更像"方向结构不足""图模型问题"还是"节点特征本身发生严重漂移"。
2. **主攻 DG-ResEGS**：按 `EGS → +self残差 → +门控 → +时间环境正则` 顺序做最小消融。它最符合 packet 中的机制证据：随机切分 EGS 强、时间切分崩；多数邻居未标注且异配；方向信息又明显有价值。因此合理策略不是废掉图，而是让模型在邻域失效时能够退回节点自身表示，并降低对特定训练时期图模式的依赖。
3. **校准/拒判直接进入交付**：不以提高 Macro-F1 为目标，而是把已有高 AUROC/AUPRC 排序能力转化成可答辩的"风险审查辅助"输出。

**显式推迟：**

* `as-of union / 全量历史溯源重建`：packet 已明确需要原始链数据工程，超出两周冲刺。
* 任何需要大规模 motif 枚举、ego-net 数据集重建、层级标签体系重构、自监督预训练的新方向：packet 没有证明现成输入/缓存存在，工程变量过多，不适合作为冲刺一首攻。
* GAT/GIN/GCN 不进入主搜索链。它们可以作为后补基线，但相较 Dir-SAGE 和 GBDT，对当前"方向性 + temporal collapse"的判别价值较低。
* packet 未枚举"深度研究报告五个方向"的完整名称，因此不能声称已逐一对应报告中的全部五项；这里只能裁定 packet 明确支持的方向。

主结论采用 **validation-first、test-once**：所有模型结构、超参数和拒判阈值均只由 train/val 决定；最终锁定方案后，temporal test 对每个 seed 仅评估一次。

## Assumptions

* temporal 协议中存在一个训练时已经使用的节点时间变量，例如区块高度，可以用于训练段内部 environment 划分。
* DG-ResEGS 中不改变现有 EGS 的基础损失权重、优化器、隐藏维度、dropout 等控制变量；这些值由本地执行者从现有 EGS 配置读取并冻结。

## Evidence Used

* 随机分层 `class_balanced_khop` 三种子 Macro-F1：
  * MLP `0.4077±0.0012`
  * SAGE `0.5785±0.0095`
  * EGS `0.6505±0.0138`
* temporal 单种子：
  * MLP `0.1255`
  * SAGE `0.1931`
  * EGS `0.2565`
  表明时间外推是当前主要性能瓶颈。
* seed42 消融：
  * SAGE `0.5868`
  * EGS 去方向 `0.5837`
  * 完整 EGS `0.6657`
  因而方向分离必须保留，至少不能在冲刺一中被随意替换。
* MIXER 同类入邻居仅 `0.4%`，多数类别低于 `15%`；`77–95%` 入边指向未标注节点。这支持"邻域表示可能在部分节点/时期失效，因此需要强 self fallback"的机制推断。
* GAMBLING 时间中位数 train `275K`、test `605K`，与 temporal collapse 一致，支持训练段内部做时间环境鲁棒化实验。
* focal loss 已严重失败至 `0.330`；因此 DG-ResEGS 不再同时改变 class-loss 机制。
* 原始时间边特征已有负作用，所以第一冲刺不重新把原始时间量直接送入网络。
* topology-aware reweighting 仅 `+0.0051`，低于既有 `+0.03` 阈值，不应继续消耗主要预算。
* Conservative 风险排序已经较强：AUPRC `0.7483±0.0231`、AUROC `0.9871±0.0006`、R@1% `0.346` 且 precision 约 `0.92`，因此校准/拒判具有直接交付价值。

2. **实验 E0：重新建立 temporal EGS 三种子锚点**

   模型：现有 EGS，不改变任何训练设置。数据：`temporal_balanced_no_temporal`。切分：原协议 train/val/test。Seeds：`42, 3407, 1234`。预算：`200 epochs`、`early-stop patience=50`。开发阶段先只记录 train/val；最终方案锁定前不查看新的 test。

   预注册目的不是 Go/No-Go，而是得到所有后续 delta 的匹配参照。

   **稳定性警戒线：** 如果 EGS 三 seed 的 val Macro-F1 标准差 `>0.03`，后续任何低于 `+0.03` 的改进均不得解释为可靠结构增益。

3. **实验 E1：Dir-SAGE 强方向基线**（新增 `src/btcaml/ext/dir_sage.py`）

   两层模型，每层分别聚合入邻居与出邻居：

   - m_in = Mean_{j:(j→i)} h_j
   - m_out = Mean_{j:(i→j)} h_j
   - h_i' = φ(W_s h_i + W_in m_in + W_out m_out)

   不使用 edge feature，不使用 edge gate。它只回答：EGS 的主要收益究竟来自"有向信息分离"，还是来自更具体的边门控结构？

   协议：主 `temporal_balanced_no_temporal`；机制辅助 `class_balanced_khop_no_temporal`（仅 val/已有冻结结果比较，不需要重新开 test）。Seeds：`42,3407,1234`；预算 `200 epochs / patience 50`；与 EGS 冻结相同 hidden size、层数、dropout、optimizer、loss。

   **预注册解释阈值：**
   * 若 temporal Dir-SAGE 相对普通 SAGE 提升 `≥0.03` Macro-F1：GO，确认方向建模具有跨 temporal 协议价值。
   * 若 Dir-SAGE 距 EGS `≤0.02`：不再把 EGS edge gating 作为核心创新，论文应把核心重述为 directed aggregation。
   * 若 Dir-SAGE 接近 SAGE、而 EGS 仍明显领先 `≥0.03`：说明 EGS 的增益不能由简单方向拆分完全解释。

4. **实验 E2：CPU GBDT 节点特征诊断**（新增 `scripts/run_tabular_baseline.py`）

   使用现有 LightGBM，仅使用 27 维 node features，不使用图、不把 `-1` 当类别。固定配置：objective=multiclass、learning_rate=0.05、num_leaves=63、n_estimators=1000、feature_fraction=0.8、bagging_fraction=0.8、reg_lambda=1.0、early stopping=50、n_jobs=全部线程、random_state=42/3407/1234。第一轮不调参。协议 `temporal_balanced_no_temporal`；主指标 Macro-F1。

   **预注册判别：**
   * GBDT ≥ EGS `+0.03`：暂停复杂 DG-GNN 扩张，先检查特征稳定性。
   * GBDT ≤ EGS `-0.03`：图结构在时间外推下仍提供明显有效信息，继续 DG-ResEGS。
   * 差值 ±0.03 内：两类信号均重要，继续 DG-ResEGS，但结论不得归因于纯拓扑。

5. **实验 E3：DG-ResEGS 主实验**（新增 `src/btcaml/ext/dg_resegs.py`）

   5.1 精确残差结构：g_i = EGSBackbone(i)（分类头之前图表示）；node-only self branch s_i = W_s2·GELU(W_s1 x_i + b_s1) + b_s2，与 g_i 同维；self branch 只用 x_i，不访问标签、未来时间、邻居标签或任何 `-1` 语义。

   5.2 门控（节点级标量 gate）：
   - u_i = [LN(s_i) ‖ LN(g_i) ‖ |LN(s_i)−LN(g_i)|]
   - α_i = σ(w2ᵀ GELU(W1 u_i + b1) + b2) ∈ (0,1)
   - h_i = LN(s_i + α_i g_i)；z_i = W_o h_i + b_o

   第一版 gate 禁止输入：测试期统计量、future degree/count、类别频率、邻居真实标签、`-1` 是否出现、原始绝对时间边特征。默认 gate 只使用 s_i、g_i 及差异。

   5.3 temporal environment：只在 temporal_balanced_no_temporal 的 train mask 内部，按协议用于 temporal split 的同一时间变量排序，划分为 3 个连续环境（E1 最早 1/3、E2 中间 1/3、E3 最晚 1/3 的 labeled train nodes；边界按 33.33%/66.67% 分位点）。边界只由 train 计算一次并写入 run config；val/test 绝不参与。不改变 edge_index，不删边。

   5.4 损失：每环境使用与 EGS 完全相同的基础分类 loss；DG 阶段用 V-REx 型风险方差惩罚 L = (1/3)Σ_e R_e + λ·Var(R_1,R_2,R_3)；λ ∈ {0.1, 0.3, 1.0} 只依据 val 选择；不同时搜索其它新超参。

   5.5 最小消融链（每步冻结数据/split/seed/hidden/EGS backbone/optimizer/lr/dropout/base loss/early stop）：
   - A0 — EGS：h_i = g_i
   - A1 — EGS + self residual：h_i = LN(s_i + g_i)
   - A2 — EGS + self + gate：h_i = LN(s_i + α_i g_i)
   - A3 — DG-ResEGS：A2 + 三环境 V-REx

   5.6 计算预算：第一级快速淘汰 seed=42、max epochs=80、patience=20、只看 val；A1/A2/A3 与 epoch-matched A0 比较。快速 No-Go：某阶段 ΔMacroF1_val < −0.01 则不进入三种子正式阶段。若 A1/A2/A3 均失败，DG-ResEGS 本冲刺结束，不盲目调 hidden size。正式候选：seeds=42/3407/1234、200 epochs、patience=50；最多晋级 A0 baseline + 一个最佳 variant。

   5.7 正式 Go/No-Go（三 seed val）：GO = ΔMacroF1̄ ≥ +0.020 且至少 2/3 seeds 正增益，且 GAMBLING/EXCHANGE/MARKETPLACE/BRIDGE 四类中不得有两类以上 F1 相对下降 >0.05，且 Conservative AUPRC 下降 ≤0.02。达到后锁配置才允许打开 temporal test。"显著提升"最终主张阈值：ΔMacroF1̄_test ≥ +0.03（相对本冲刺匹配三 seed EGS）。+0.02~+0.03 可作为有潜力结果，不包装为主要突破。预测区间（非已验证结果）：temporal Macro-F1 绝对提升约 +0.02 ~ +0.06。

6. **实验 E4：时间段鲁棒性诊断**（新增 `scripts/temporal_diagnostics.py`）

   不训练新模型。将 val 依时间顺序切成 3 个连续、等 labeled-node 数量的 slice，报告 Macro-F1、每类 F1、prediction class distribution、mean confidence、Conservative AUPRC、EGS/Dir-SAGE/GBDT/DG-ResEGS 对比。诊断标准：若 DG-ResEGS 总体提升来自早期 val 而最后 1/3 时间段 ΔF1_latest ≤ 0，则不得称为"时间鲁棒性改善"；至少要求 ΔF1_latest > 0 且三 slice 中至少两个为正。

7. **实验 E5：校准与拒判交付**（新增 `scripts/evaluate_calibration.py`）

   不修改模型训练。对最终锁定的 EGS baseline 与 DG-ResEGS winner，从 best.pt 重新推理得到完整 logits/probabilities。

   校准规则：只用 val logits 拟合单一温度 T* = argmin_T>0 NLL_val（优化 log T，限制 log T ∈ [-3,3]）；test 绝不参与拟合/选择/调节；不做 per-class/vector scaling。

   指标：Global ECE（15 个 equal-frequency bins，confidence=max_k p_k）；Classwise-ECE（每类 one-vs-rest、10 bins、报 11 类及 macro）；Multiclass Brier；AURC（按 confidence 降序的 risk-coverage 离散积分，报 Risk@5/10/25/50/75/100% coverage）；NLL 附报不作为核心指标。

   拒判阈值：只在 val 上选全局 confidence threshold，定义三个 operating points（最大 coverage 且 empirical risk ≤5%/≤10%/≤20%；达不到则标 unavailable）；阈值由 val 锁定后直接应用 test。

   calibration Go/No-Go：GO = ECE 相对下降 ≥20% 或 Brier 绝对下降 ≥0.005，同时 argmax 预测不因温度缩放发生实质变化、AURC 恶化 ≤0.002。不满足则不声称已校准，但仍可提交未校准 risk-coverage 曲线。

   最小答辩展示：表1 模型性能（EGS/Dir-SAGE/DG-ResEGS：Macro-F1 mean±std、GAMBLING/EXCHANGE/MARKETPLACE/BRIDGE F1、Conservative AUPRC/R@1%/R@5%）；表2 可信度（Raw/Calibrated × EGS/DG-ResEGS：ECE、classwise-ECE macro、Brier、AURC）；图1 reliability diagram（校准前后）；图2 risk-coverage curve（EGS vs DG-ResEGS）；图3 temporal val 三时间 slice Macro-F1。

## Risks

* 最大风险：冻结的 temporal 0.2565 与 temporal_balanced_no_temporal 不是同一协议。缓解：先建立 matched EGS baseline，所有新模型只与 matched baseline 比。
* DG-ResEGS 可能只提升平均 val，不改善最晚时间段。缓解：预注册 latest temporal slice 必须改善，否则不允许称时间鲁棒。
* self branch 可能让模型退化成 MLP。缓解：使用 gated residual 而非替换图表示；记录 α 分布。
* gate 可能只学习类别/训练时期 shortcut。缓解：第一版 gate 不输入绝对时间、度数、标签统计，只从 self/graph representation 计算；再用三个时间 slice 检验。
* 环境正则可能因极小类在部分 environment 缺失而不稳定。缓解：环境 loss 按全部 labeled samples 计算，不做每环境每类强制重采样。
* V-REx λ 太大导致欠拟合。缓解：只搜索 {0.1,0.3,1.0}；seed42×80 epochs 快速淘汰。
* 参数量增加造成不公平优势。缓解：记录参数量；必要时补 parameter-matched 控制。
* Dir-SAGE 可能削弱"EGS 方向分离是核心贡献"的叙事。这是必须验证的科学问题，若简单 Dir-SAGE 已达 EGS 应主动修改贡献表述。
* 温度缩放可能改善 ECE 但不改善风险排序。AURC 单独报告，不把 ECE 改善等价为检索性能改善。
* 现有 protocol graph 可能包含未来交易边。DG-ResEGS 不能解决；即使 temporal test 提升也只能表述为"当前 temporal protocol 下更鲁棒"。
* 两周 CPU 预算被大量三 seed ablation 消耗。缓解：A1/A2/A3 先 seed42×80 epochs，只有一个 winner 晋级三 seed×200 epochs。
