## 1. 决策问题与阶段边界

### 1.1 本研究要回答的问题

分区版本（as-of `C_{t_j}` vs 后视 `C_{T_j}|V_j`）的差异，是否改变**下游可检验对象**——实体类型标签的投影与冲突结构（路线甲），或按冻结规则排出的实体名单（路线乙）。

### 1.2 明确的边界（不得越界）

| 边界 | 内容 |
| --- | --- |
| 使用者 | VASP 合规调查员是**拟议使用者**，**不声称**合规效用或使用者收益 |
| 标签语义 | `0–10` 是**实体类型**，不是 AML 风险标签；`-1` 是未标注，不作负类 |
| 聚类 | 启发式聚类是**近似**，不是主体所有权真值 |
| 措辞 | 无逐记录标签时间时，结果只能标"**回顾性敏感性分析**"，禁用"历史部署性能""当时可识别" |
| 门控 | 本协议通过并冻结**之前**，不读标签、不训练、不打开测试集 |

### 1.3 与 S0 的继承关系

**继承**（不重复论证）：原始链前缀与字节冻结、`script_id` 标识规则、union 日志与重放语义、协作交易过滤 `F_pub`/`F_wide`/`F_none`、四个 cutoff 与 `W=2,016`。

**不继承**：S0 的 1% 阈值、`p_merge`/`p_rewrite` 主判据、S0 的三态决策规则、`H` 的各 horizon 设置。

### 3.2 标签准入判据（须全部满足）

1. **逐来源许可**核验完成，含占比 86.1% 的 BitcoinTalk（未完成前不得读取标签）；

4. 无法核验的项**分列报告**，不得以推断替代。

### 3.3 标签时间与回顾性边界

- `addresses.csv` 自身无时间列，**该 CSV 不能提供逐记录可得时间**；
- 外部来源（`BitcoinTalkThreads.tar.gz` 的逐条 `date`、次级来源版本历史）**须逐项核验**，不得预先断言不可补齐；
- **回顾性 S1 与要求历史时点有效标签的 S2 分开判定**：S1 可做不等于 S2 可做。

## 4. 评测单位

### 4.1 共同口径

| 维度 | 取值 |
| --- | --- |
| `window_id` | 沿用 S0 四 cutoff：`t181440`, `t199584`, `t215712`, `t225792` |
| `filter_profile` | `F_pub`, `F_wide`（主）；`F_none`（诊断） |
| 配对方式 | B/C **同支持、同交易窗口**；唯一差异是分区版本 |

### 4.2 路线甲的单位（待定稿）

`script-level label anchor` 配对集。须定义：标签投影方向（地址→script→实体）、B/C 实体匹配规则、多对多投影的分母、未投影与冲突的处置。

### 4.3 路线乙的单位（待定稿）

`(window_id, filter_profile, K)` 下的实体队列，`K ∈ {1%, 5%}`。须定义：评分函数、tie-break、队列去重。

## 5. 主要指标

### 5.1 路线甲候选指标

标签投影冲突率、未投影比例、配对标签一致率；若标签可用且切分允许，Macro-F1、逐类 F1、macro one-vs-rest AUPRC 的 B/C 配对差。

### 5.2 路线乙候选指标

名单重叠率 `overlap(K) = |Q_B(K) ∩ Q_C(K)| / K`。

**重要限制（导师裁定，须原样保留）：** 在评测单位、候选打分方式与 `K` 未定义时，`overlap(K)` **不能证明复核质量或使用者收益**。它只衡量稳定性。**本草案不把它写为唯一主指标。**

### 5.3 路线乙的前置义务

若要采用 `overlap(K)` 作指标，**必须先冻结一个可辩护的评分函数**，且：

- 评分函数只能使用 `t_j` 时可见信息；
- 不得依据结果调整；
- 须说明它**比 S0 的比率型结论多回答什么**。

## 6. 标签冲突与缺失处理

| 情形 | 草案处理 | 状态 |
| --- | --- | --- |
| 同一 cluster 多类型 | 记为冲突，不多数票覆盖 | 沿用协议 §9 |
| 冲突的最终处置 | **拟改为**"标记冲突 + 明确移除规则 + 报告分母" | **待导师批准** |
| `-1` | 未标注，不作负类 | 沿用协议 §9 |
| 无法投影 | 记录比例，不静默丢弃 | 沿用协议 §9 |

来源侧原做法是"冲突即不标注"（arXiv 2411.10325）。改动理由：原做法丢失信息且不可追溯。**此项为方法论变更，不在本草案中单方生效。**

## 7. 基线与模型纪律

首轮基线：多数类、逻辑回归、一个树模型、MLP、现有 GraphSAGE 与 EGS。**若简单非图模型已能解释 B/C 差异，不新增 GNN 架构。**

- 同一组五个种子 `[42, 3407, 1234, 2026, 8675309]`；最多 20 个验证集超参配置；
- 不新增 GNN 架构或预训练任务；
- 标准化、特征选择、阈值、校准**只在训练／验证期拟合**；
- 测试集**只打开一次**，且须在配置、manifest、decision log 锁定后。
