## 第 2 步：数据协议构建 v2.2

这是最关键的一步。

我要实现四套数据协议：

```text
Protocol A: current_topk_baseline
- 直接兼容你当前 data.pt
- 用于复现现有结果和展示 TopK 偏差

Protocol B: label_preserving
- 强制保留原始数据库中 11 类全部有标签节点
- 不允许 PONZI / RANSOMWARE / MIXER 等类别再次丢失

Protocol C: class_balanced_khop
- 每类有标签节点统一 k-hop 邻域扩展
- 解决只增强 BRIDGE 的不公平问题

Protocol D: temporal_balanced
- 保留 11 类标签
- 同时支持时间划分
- 用于论文主实验
```

同时实现：

```text
1. 11 类 label map
2. NONE / unlabeled 逻辑
3. conservative_sensitive / extended_sensitive 风险分组
4. degree cap 超级节点截断
5. per-class sampling budget
6. block-height temporal split
7. global temporal split
8. class-wise temporal split
9. log1p + clip + train-only normalize
10. edge temporal features: duration / frequency / recency / avg_sent / amount_range
```

这一阶段你需要在本地跑：

```bash
python scripts/audit_raw_labels.py
python scripts/build_protocol_dataset.py --protocol label_preserving
python scripts/build_protocol_dataset.py --protocol class_balanced_khop
python scripts/build_protocol_dataset.py --protocol temporal_balanced
python scripts/compare_protocols.py
```

然后把输出的 protocol report 发给我，我再根据实际结果调采样预算。
