# 📊 论文方法（必须完全按以下实现）

## 1️⃣ 节点特征（Feature Matrix）

每个节点使用 4 个特征：

X = [degree, total_in, total_out, cluster_size]

---

## 2️⃣ 标准化（Z-score）

对每个特征做标准化：

Z(x) = (x - mean(x)) / std(x)

---

## 3️⃣ 节点重要性评分（核心公式）

定义每个节点的重要性分数：

$$FinalScore = 0.3 × Z(degree) + 0.2 × Z(total_in) + 0.2 × Z(total_out) + 0.3 × Z(cluster_size)$$
👉 该评分用于从超大图中筛选“关键节点”

---

## 4️⃣ 节点筛选策略（关键步骤）

步骤如下：

① 按 FinalScore 对所有节点排序

② 选择前 K 个节点：
K = config["preprocessing"]["max_nodes"]

---

## 5️⃣ 稀有类别增强（必须实现）

问题：类别极度不平衡（例如 BRIDGE 很少）

解决策略：

① 找到 lable  == "BRIDGE" 的节点

② 查询这些节点在图中的邻居（通过 edges 表）

③ 将这些邻居加入最终节点集合

最终：

selected_nodes = TopK_nodes ∪ bridge_neighbors

---

## 6️⃣ 子图构建（Subgraph）

只保留满足条件的边：

source ∈ selected_nodes 且 target ∈ selected_nodes

构建子图：

G_sub = (selected_nodes, filtered_edges)

---

## 7️⃣ 标签构建（Label）

标签来自node节点字段：

label_map = {
"NONE": 0,
"INDIVIDUAL": 1,
"BET": 2,
"GAMBLING": 3,
"EXCHANGE": 4,
"BRIDGE": 5
}

规则：

* 不在 target_labels 中 → 0（NONE）
* 没有标签 → 0

---

## 8️⃣ 半监督训练（关键）

大部分节点没有标签，因此：

train_mask = (y != 0)

同时生成：

* val_mask（随机划分）
* test_mask（随机划分）

---

## 9️⃣ 构建 PyTorch Geometric 数据

最终需要：

* x：FloatTensor [N, 4]
* edge_index：LongTensor [2, E]
* y：LongTensor [N]
* train_mask / val_mask / test_mask
