## 实验复现

快速验证（smoke test）：
```powershell
python scripts/verify_experiments.py --smoke --dry-run   # 查看所有验证命令
python scripts/verify_experiments.py --smoke              # 实际运行smoke验证
```

完整复现关键实验：
```powershell
python scripts/verify_experiments.py --dataset CBK        # 只跑CBK相关
python scripts/verify_experiments.py                      # 跑全部关键实验
```

单个实验复现（以EGS seed42为例）：
```powershell
python scripts/run_benchmark.py --data data/processed/protocols/class_balanced_khop.pt --models edge_gated_sage --seed 42 --run-name paper_verify_egs
```
