  arXiv:2411.10325
  DB: ~252M nodes, ~786M edges
  data.pt subgraph: 350K nodes, 17M edges (TopK 0.14%)

KEY FINDINGS:
  1. Raw dataset 700x larger than subgraph - TopK selection introduces bias
  2. Amount features extreme long-tail (skew >> 100)
  3. Block heights span multi-year activity
  4. Edge temporal info enables time-aware modeling
  5. Directed edges carry fund-flow semantics
  6. Self-loops exist but are rare

RESEARCH IMPLICATIONS:
  - Class-balanced sampling over TopK
  - Temporal split via block heights
  - log1p + robust scaling for features
  - Edge-aware message passing
  - Direction-aware aggregation
