## 固定抽取规则

- `label availability time` 必须与事件时间和数据采集时间分列记录。
- 数据集论文的规模、年份、标签和许可必须回到原始论文或官方仓库。
- 每个结论定位到页码、章节、表格或图；无法定位则不得升为 `interpretation-verified`。
- DOI 存在只证明来源可定位，不证明论文支持当前主张。
- `Sch24` 是工作区 cite key，不代表正式年份；官方 Scientific Data 页面显示 2025 年发表，BibTeX 年份必须使用 2025。
